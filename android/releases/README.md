# Install Machine Learner on Android

Download [`machine-learner-debug.apk`](https://github.com/harihari1989/machinelearner.github.io/raw/refs/heads/codex/simplify-android-learning-path/android/releases/machine-learner-debug.apk) directly on an Android 8.0 or newer phone.

1. Open the downloaded APK from Files, Chrome, or your downloads notification.
2. If Android asks, allow that app to install unknown apps.
3. Tap **Install**, then turn the unknown-app permission off again.

This is a debug-signed development build with application ID `io.github.machinelearner`. It is not signed for Play Store distribution. The APK includes the full website, Manim media, ONNX model, and bundled Python runtime.
